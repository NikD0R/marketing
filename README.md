# 📈 DMarketing Agency
DMarketing Agency is a modern responsive website for a digital marketing agency, created to showcase services, case studies, clients, and contact information. The project has a clean, professional design and is focused on user experience to effectively represent the company online and attract potential customers.

<br>

## 🔗 Live Preview
 👉 [View Live Version](https://dmarketing-agency.netlify.app/)

<br>

## 🛠 Technologies Used

### Core
  - **HTML5** — Semantic markup
  - **SCSS** — Advanced styling with variables and placeholders
  - **JavaScript (ES6+)** — Interactive logic and integration

### Libraries & Tools
  - **jQuery** — DOM manipulation and event handling
  - **Slick Carousel** — Fully responsive and touch-enabled sliders for testimonials and services
  - **BEM** — CSS naming convention for modularity
  - **MixItUp** — High-performance library for animated filtering and sorting of portfolio items
  - **Fancybox (@fancyapps/fancybox)** — Elegant lightbox for viewing images and project details

### Development & Deployment
  - **Gulp** — Task runner for building, minification, and image optimization
  - **BrowserSync** — Live reloading during development
  - **Netlify** — Hosting and continuous deployment

## ✨ Features
  - **Responsive Design:** Completely optimized for all screen sizes, from mobile phones to high-resolution desktops.
  - **Portfolio Filtering:** Smooth and animated sorting of projects by categories using MixItUp.
  - **Interactive Sliders:** Elegant touch-responsive carousels powered by Slick-carousel for showcasing the team and client feedback.
  - **Media Lightbox:** High-quality image previews and modal galleries via Fancybox.
  - **Pixel Perfect Execution:** Accurate implementation of the design layout with attention to spacing and typography.
  - **Optimized Workflow:** Gulp-driven build process ensuring minified CSS/JS and optimized assets for rapid loading speeds.
  - **Smooth Navigation:** User-friendly navigation with smooth scrolling to sections and active state tracking.
